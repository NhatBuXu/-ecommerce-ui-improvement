## 4. Nội dung các bài thực hành

### Lab 08 – JavaScript 1: Language Foundations

- Làm quen với cú pháp JavaScript.
- Sử dụng biến, kiểu dữ liệu và hàm.
- Thực hành các cấu trúc điều khiển.
- Làm việc với String, Date, Array và Object.
- Sử dụng Browser Console để kiểm tra mã nguồn.

### Lab 09 – JavaScript 2: DOM and Events

- Truy xuất và lựa chọn các phần tử HTML thông qua DOM.
- Thay đổi nội dung, thuộc tính và kiểu hiển thị.
- Tạo, thêm và xóa các phần tử HTML.
- Xử lý sự kiện người dùng.
- Làm việc với Form và kiểm tra dữ liệu đầu vào.

### Lab 10 – JavaScript 3: jQuery

- Cài đặt và sử dụng thư viện jQuery.
- Thực hành jQuery Selectors.
- Xử lý sự kiện bằng jQuery.
- Thao tác với các phần tử DOM.
- Xây dựng hiệu ứng Animation.
- Thực hiện GET Requests và xử lý dữ liệu trả về.
